# SP Ultra 1.0.0

一款支持 SFTP 与 SCP 远程传输协议的 macOS 软件，也是面向 Apple Silicon 的 SecureFX 平替产品。

## 主要功能

- 原生 SwiftUI 双栏文件管理与会话管理。
- 应用内 SFTP/SCP，不依赖系统命令行工具。
- SCP 自动兼容旧设备与越狱 iOS。
- 实时传输进度、速度以及 SFTP 断点续传。
- 远程创建、删除、重命名、权限编辑和 UTF-8 文本在线编辑。
- 自定义初始远程路径列表，默认仅包含 `/`。
- macOS 钥匙串凭据、TOFU 主机指纹和受控指纹库恢复。
- 内嵌 MCP 服务。

## 安装包

- `SPUltra-1.0.0-arm64.dmg`
- 仅支持 Apple Silicon 与 macOS 15.0 或更新版本。
- 当前包使用 ad-hoc 签名，未进行 Apple Developer ID 公证。
